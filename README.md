# Paslauski

Portfólio pessoal de Ígor Paslauski — uma experiência editorial com cena Three.js, cases e um mapa da trajetória profissional.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- Three.js via `@react-three/fiber` e `@react-three/drei`
- Lenis para scroll suave

## Desenvolvimento

```bash
npm install
npm run dev
```

O servidor sobe em `http://localhost:8080`.

```bash
npm run build
npm run preview
```

## Conteúdo

Textos, experiências, projetos e credenciais ficam em `src/content`. A cena 3D vive em `src/components/canvas`. As seções da narrativa estão em `src/components/sections`.

## Deploy

O site é publicado em [paslauski.com.br](https://paslauski.com.br/) via GitHub Pages.
